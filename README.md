# sales-performance-analysis
# description: A sales performance analysis project using Excel and SQL to clean, analyze, and visualize sales data, tracking revenue, profit, trends, and top products/regions through dashboards and SQL queries for data-driven insights.
# about: Sales Analysis Report is a data-driven project built with Excel and SQL to analyze sales performance and business growth. It covers data cleaning, KPI tracking, and dashboard creation to visualize revenue trends, top-selling products, regional performance, and customer insights.

# Tools: Excel (Pivot Tables, Charts, Dashboards) | SQL (Joins, Group By, Window Functions)

# Goal: To turn raw sales data into clear, actionable insights for better decision-making.
